# Правила работы

## Git

- После каждого завершённого изменения делать **локальный git commit**.
- Коммит делать сразу, не накапливать десятки изменений.
- Сообщение коммита — по-русски, коротко и по делу.
- Перед коммитом проверять `git status`.
- **Никогда не делать `git push` и не публиковать на GitHub без явной команды пользователя.**
- Рабочий репозиторий: `C:\Users\admin\Documents\dsh-local-stt`.
- Каталог `engines/` (движки и модели, ~1,6 ГБ) в Git не хранится; он лежит рядом локально и указан в `.gitignore`.

## Проверки

- Перед коммитом: `node --check`, живой тест провайдера, закрытые порты после теста.
- Не оставлять фоновые серверы.
- Секреты и токены не коммитить.
