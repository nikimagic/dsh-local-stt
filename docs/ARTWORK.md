# Графика плагина

## Иконка

Автор — **NikiMagic**, нарисована для этого проекта. Внешних ассетов, стоков
и чужих логотипов нет.

- Стиль и палитра взяты у соседнего проекта автора **MagicControl**:
  фон `#171B33 → #0B0B15`, градиент знака `#7C3AED → #3B82F6 → #22D3EE`.
- Смысл: микрофон со звуковыми волнами — локальное распознавание речи.
- Исходник: [icons/local-stt.svg](icons/local-stt.svg).
- Растр собирается скриптом [../scripts/make-icon.py](../scripts/make-icon.py):
  рисуется в 4× и уменьшается, поэтому края гладкие.

```text
python scripts/make-icon.py
```

Скрипт пишет четыре файла: `assets/icon-512.png`, `assets/icon-180.png`,
`icon.png` (иконка пакета для DSH) и `docs/icons/local-stt.png` (иконка для
каталога плагинов).

## Лицензия

Графика распространяется по той же лицензии MIT, что и код проекта (см.
[LICENSE](../LICENSE)).

## Старые значки

Иконки `whisper.svg` и `gigaam.svg` относились к прежнему составу плагина
(GigaAM + whisper.cpp) и удалены вместе с этими провайдерами. Знак `G + W`
на старом PNG больше не используется.
