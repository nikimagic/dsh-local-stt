# 0.3.11 — движки при первом запуске

Движки (`flm.exe`, `audiocpp_server.exe` и их dll) больше не нужно раскладывать
руками: плагин скачивает архив движка и распаковывает его сам, затем готовит
модель.

## Что появилось

- Манифест архивов движков `lib/engines.js`: имя архива, размер, SHA-256,
  каталог установки и файл-маркер.
- Скачивание архива с докачкой, проверка SHA-256, распаковка своим zip-модулем
  (`lib/zip.js`) без внешних зависимостей.
- Состояния подготовки: `unprepared` → `downloading` (архив) → `loading`
  (распаковка) → `downloading` (модель) → `standby`.
- Оценка объёма в карточке учитывает движок и модель вместе.
- Ошибки движка показываются в карточке с причиной: `http`, `integrity`,
  `storage`, `network`.

## Архивы

Собираются из `engines\...` скриптом:

```text
node scripts/pack-engines.mjs
```

Скрипт пишет `dist\flm-1.0.13-win-x64.zip` (39,1 МБ) и
`dist\audiocpp-0.9.4-win-x64.zip` (35,7 МБ), после чего сам записывает их
размер и SHA-256 в `lib/engines.js`. Архивы загружаются в отдельный релиз
GitHub, тег `engines-1`; базовый адрес можно переопределить полем
`engines.baseUrl`.
