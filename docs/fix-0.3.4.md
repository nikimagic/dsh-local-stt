# 0.3.4 — идентификация конкретного запуска

## P1: повторное использование PID другим экземпляром того же exe

PID-файл теперь хранит не только номер, но и **время создания процесса**:

```json
{
  "pid": 11440,
  "command": "...\\flm.exe",
  "port": "52626",
  "createdAt": "2026-11-16T08:35:54.7276300Z"
}
```

При восстановлении:

- путь исполняемого файла должен совпасть;
- `createdAt` должен совпасть с текущим временем создания PID;
- `portPid`, если порт занят, должен указывать на тот же PID.

Если PID переиспользован другим экземпляром того же `flm.exe`,
`createdAt` не совпадёт — процесс не будет остановлен.

## Проверки

- `node --check` — успешно.
- Живой `flm.exe` на порту `52627`, PID-файл с чужим `createdAt`:
  процесс остался жив, файл удалён.
- Живой сервер на `52626` с корректным `createdAt`:
  `cleanupStale()` остановил его, порт закрылся.
- После тестов порты закрыты.

Публикация не выполнялась.
