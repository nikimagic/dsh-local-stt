# Ревизия 0.3.4

Проверен коммит `c8adda0`; установленные файлы пакета совпали с репозиторием.

## Что исправлено

На изолированных имитациях проверены пять сценариев: другой `createdAt`,
совпадающий процесс с закрытым портом, чужой владелец порта, старый PID без
владения портом и старый PID с владением портом. Результаты соответствуют
описанию исправления. Реальные чужие PID в этих проверках не завершались.

## Оставшиеся замечания

1. **P2: два живых DSH с одним профилем не различаются.** Второй экземпляр
   читает тот же PID-файл. Путь, время создания и порт действительного сервера
   первого экземпляра совпадают — `cleanupStale()` останавливает его, хотя
   первый DSH ещё может им пользоваться. Это воспроизведено на имитации;
   возможность параллельного запуска двух полных DSH с одним профилем в данной
   ревизии отдельно не проверялась.
2. **P2: при недоступной проверке личности PID может потеряться позже.**
   `cleanupStale()` сохраняет старый файл при ошибке проверки, но возвращает
   управление. Если порт закрыт, последующий запуск нового процесса вызывает
   `writePid()` и перезаписывает тот же файл. Старый живой процесс может
   остаться без записанного PID. Это вывод по коду; живое воспроизведение
   сценария с недоступным PowerShell не проводилось.
3. **Отмена:** `cancel()` останавливает owned-процесс, но сама не отменяет
   сигнал и цикл `startServer()`. При неудачной остановке ожидание может
   продолжиться до timeout. Это остаётся открытым замечанием автора.
