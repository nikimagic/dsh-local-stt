# dsh-local-stt 0.3.16 — надёжная подготовка ресурсов

Релиз исправляет проблемы, обнаруженные при повторной ревизии версии 0.3.15, и укрепляет загрузку движков и моделей.

## Главное

- **Восстановление HTTP 416:** при отказе сервера продолжить докачку плагин удаляет устаревший `.part` и один раз повторяет запрос с начала.
- **Безопасные загрузки:** размер проверяется до записи на диск, а файл публикуется только после проверки размера и SHA-256.
- **Официальные источники первыми:** модели — Hugging Face → зеркало → локальная папка; движки — официальный архив → локальный архив → резервный релиз.
- **Устойчивое завершение:** отмена и отключение провайдера ожидают завершения запуска и активного распознавания; чужой PID-файл сохраняется.
- **Корректный статус проверки:** кнопка сообщает об успехе лишь после проверки обоих встроенных провайдеров.

## Установка и обновление

В DSH откройте **Плагины → Добавить плагин**, установите `dsh-local-stt` из индекса проекта и перезапустите DSH:

```text
https://cdn.jsdelivr.net/gh/nikimagic/dsh-local-stt@main/docs/index.json
```

Движки и модели хранятся вне пакета в каталоге `~/.dsh/dsh-local-stt/engines`; обновление плагина не удаляет их. Отсутствующие ресурсы готовятся автоматически.

## Проверки

Полный набор проекта: 120 проверок в 19 файлах. Запуск: `node scripts/test.mjs`.

После обновления проверьте готовность в карточке плагина кнопкой **«Проверить обновления»**. Живой запуск движков требует совместимого оборудования и драйверов.
