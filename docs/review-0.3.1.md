# Ревизия 0.3.1

Проверен код `d1d1791`; установленный `index.js` и пакетные файлы совпадали
с репозиторием по SHA-256. Публикация и push в рамках ревизии не выполнялись.

## Существенные проблемы

1. **P1: PID из устаревшего файла может принадлежать другому процессу.**
   `cleanupStale()` проверяет существование PID и ответ сервера, но не
   проверяет, что этот PID принадлежит именно запущенному плагином серверу
   или владеет указанным портом. После повторного использования PID и при
   работающем сервере функция направит `taskkill` в посторонний процесс.
   Воспроизведено изолированным mock-тестом без остановки реальных процессов.

2. **P2: живой процесс с закрытым портом теряется при восстановлении.**
   В `cleanupStale()` при живом PID и не отвечающем сервере процесс не
   останавливается, а PID-файл удаляется. Это отдельная ветка от `stopOwned()`,
   где действительно проверяются и PID, и порт. Условия воспроизведены mock-тестом.

## Что подтверждено

- Очередь: отменённая ожидающая запись отклоняется до завершения первого
  запроса, её задача не запускается. Проверено mock-тестом.
- Whisper и Orukeet действительно распознали WAV на изолированных портах:
  полный вызов с запуском и остановкой — 5.30 и 4.99 с соответственно.
  После каждого вызова его PID отсутствовал, тестовый порт был закрыт.
  Это один прогон, не среднее и не замер микрофонного UI.
- В коде прямого запуска `windowsHide: true`, `detached` отсутствует.
  Отдельной визуальной проверки окон консольного хоста не проводилось;
  нулевой MainWindowHandle одного процесса сам по себе её не заменяет.
- `standby` поддерживается установленным DSH SDK и считается готовым к записи
  в штатном интерфейсе голосового ввода.
- Штатный DSH API принимает только канонический mono PCM16 WAV 16 кГц с
  `fmt` по смещению 12 и `data` по смещению 36. Ошибка расчёта произвольного
  WAV с дополнительными чанками не проявляется через этот API: такой WAV
  отвергается раньше. При прямом вызове провайдера ограничение остаётся.
- `baseUrl` может указывать наружу. При значении по умолчанию адрес локальный;
  абсолютное обещание локальности не обеспечивается при произвольной настройке.
- Локальный индекс ссылается на 0.3.0. Это зафиксированное состояние до
  отдельной команды на публикацию; оно не доказывает ошибку работы 0.3.1.
