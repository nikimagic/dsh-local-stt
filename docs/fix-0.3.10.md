# 0.3.10 — модели при первом запуске

Раньше модели нужно было класть руками. Теперь плагин готовит их сам и
показывает прогресс в штатной карточке голосового ввода DSH.

## Что появилось

- Состояние `unprepared`, пока моделей нет, с оценкой объёма и времени.
- `prepare()` скачивает недостающие файлы и публикует `downloading` с
  байтами по текущему файлу.
- Два источника: Hugging Face по закреплённой ревизии и локальная папка с
  исходниками (`localSource` / `DSH_LOCAL_STT_SOURCES`). При сетевой ошибке
  Hugging Face повторяет запрос через `hf-mirror.com`.
- Ревизии закреплены, каждый файл проверяется по размеру и SHA-256.
- Недокачанный файл остаётся как `.part`; следующая попытка продолжает его
  через `Range`, а не начинает заново.
- `transcribe()` без моделей отвечает ошибкой со списком недостающих файлов.

## Заодно исправлено

- Состояние `checking` публиковалось без `startedAt` и не проходило схему
  клиента DSH 0.2.2-rc.3. Теперь `startedAt` есть.
- Подсказка при отсутствии движка ссылалась на несуществующий
  `start-flm.bat`.
