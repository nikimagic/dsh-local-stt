# dsh-local-stt 0.3.12 — самодостаточная установка

Плагин ставится в профиль как обычный пакет и сам готовит движки и модели при
первом запуске. Вручную раскладывать 1,7 ГБ больше не нужно.

## Что появилось

- **Движки скачиваются и распаковываются автоматически.** Архивы лежат в
  релизе `engines-1`, собственный zip-распаковщик без внешних зависимостей.
- **Модели качаются с Hugging Face** по закреплённым ревизиям. Второй
  источник — папка проекта (`localRoot`, `localSource`): ни сети, ни трафика.
- **Кнопка «Проверить обновления»** в карточке плагина: сверяет SHA-256
  движков и моделей и сравнивает версию с GitHub.
- **Проверка ничего не удаляет.** Движки живут в версионных каталогах, новый
  ставится рядом со старым; повреждённый каталог не трогается.
- Состояния подготовки в штатной карточке голосового ввода: `unprepared` →
  `downloading` → `loading` → `standby`, с байтами и процентами.

## Исправления

- Манифест модели больше не затирает её строковое имя: в запрос уходит
  `whisper-v3:turbo` / `orukeet_q8_0`, а не `[object Object]`.
- Состояние `checking` публикуется с `startedAt` и проходит схему клиента DSH.
- Кнопка проверки стоит в шапке карточки плагина, рядом с «Удалить».

## Требования

- Windows x64.
- NPU-путь: Ryzen AI 300 (XDNA2) с драйвером; альтернатива — Vulkan.
- DSH 0.2.2-rc.1 и новее, штатный `@deepseek-ai/dsh-experimental-voice-input-bundle`.
- Для офлайна: `localRoot` на каталог проекта или `localSource` на `engines`.

После установки нужен перезапуск DSH.
