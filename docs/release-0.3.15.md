# dsh-local-stt 0.3.15 — данные вне пакета

Плагин ставится пакетом, а движки и модели лежат отдельно и переживают
обновления.

## Главное

- **Данные вне пакета:** `C:\Users\<user>\.dsh\dsh-local-stt\engines`.
  Пакет весит 60 КБ, обновление занимает секунду и не трогает 1,7 ГБ.
- **Перенос автоматический:** старая раскладка внутри пакета переезжает
  переименованием, без копирования.
- **Официальные источники движков:** `ROCm/FastFlowLM` 1.0.13 и
  `0xShug0/audio.cpp` 0.9.4; наш архив в `engines-1` — резерв.
- **Проверка ничего не удаляет:** повреждённый каталог движка остаётся,
  staging проверяется до переноса.
- **Кнопка «Проверить обновления»** в шапке карточки плагина: SHA-256 движков
  и моделей плюс версия с GitHub.

## Каталог данных

Порядок выбора каталога данных: `engines.dir` → `DSH_LOCAL_STT_ENGINES` →
`<DSH_HOME>\dsh-local-stt\engines` (`DSH_HOME` по умолчанию `~/.dsh`).

## Иконка

Новая: микрофон со звуковыми волнами в стиле MagicControl, палитра
`#7C3AED → #3B82F6 → #22D3EE` на фоне `#171B33 → #0B0B15`. Исходник
`docs/icons/local-stt.svg`, сборка `python scripts/make-icon.py`.

## Тесты

41 проверка в семи файлах: zip, загрузка файлов, движки, модели, провайдер,
клиентский модуль, пути данных.

## Требования

- Windows x64, DSH 0.2.2-rc.1 и новее, штатный голосовой ввод DSH.
- NPU-путь: Ryzen AI 300 (XDNA2) с драйвером; альтернатива — Vulkan.
- Для офлайна: `localRoot` в профильном слое или `localSource` на `engines`.

После установки нужен перезапуск DSH.
