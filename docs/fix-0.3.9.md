# 0.3.9 — переносимый конфиг Orukeet

Путь к модели в минимальном конфиге был абсолютным:

```text
C:/Users/admin/.dsh/plugins/dsh-local-stt/...
```

Теперь он относительный:

```json
"path": "../../models/Orukeet-GGUF/orukeet-q8_0.gguf"
```

`audio.cpp` разрешает его относительно каталога `config`, поэтому конфиг
работает и при `DSH_LOCAL_STT_ENGINES`, и после переноса плагина.

Проверка: Orukeet распознал фразу за 5,9 с, порт 8028 закрыт.

Добавлен [docs/ENGINES.md](ENGINES.md) — как собрать полный комплект
движков и моделей, которые не входят в Git-пакет.

Публикация и push не выполнялись.
