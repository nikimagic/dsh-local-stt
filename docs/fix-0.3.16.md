# 0.3.16 — чистая установка Orukeet и таймауты

Исправления по ревизии 0.3.15.

## P1: в официальном архиве audio.cpp нет конфига плагина

Официальный архив `audio-v0.9.4-bin-windows-x64-vulkan.zip` содержит
`audiocpp_server.exe`, dll и `model_specs`, но **не содержит**
`config/audio-vulkan.json`, который плагин передаёт серверу аргументом
`--config`. Установка при этом считалась успешной: проверялось только наличие
исполняемого файла.

Что сделано:

- конфиг создаётся самим плагином при установке движка (порт, Vulkan,
  относительный путь к модели `../../models/Orukeet-GGUF/orukeet-q8_0.gguf`);
- проверка готовности движка смотрит на **все** обязательные файлы
  (`audiocpp_server.exe` и `config/audio-vulkan.json`), а не только на бинарник;
- если движок уже установлен, но конфига нет (например, поставлен из
  официального архива), конфиг дописывается на месте без удаления и
  перекачивания;
- в манифест установленных файлов попадает и созданный конфиг, поэтому
  дальнейшая проверка SHA-256 его тоже покрывает.

## P1: перенос данных со старой версии

Перенос раскладки из пакета работает, только пока старый каталог пакета ещё
существует. При обновлении через pnpm каталог заменяется целиком, поэтому
переход `0.3.14 → 0.3.15` переносом не гарантируется: движки и модели в этом
случае скачиваются заново.

Это ограничение описано в [fix-0.3.15.md](fix-0.3.15.md). Начиная с 0.3.15
данные лежат вне пакета, и последующие обновления их не затрагивают.

## P2: кнопка проверки и чужие провайдеры

Кнопка «Проверить обновления» теперь берёт только `whisper-npu` и
`orukeet-vulkan`. Чужие ASR-провайдеры из каталога голосового ввода не
запускаются и на итоговый статус не влияют.

## P2: таймаут получения ответа

Добавлен таймаут ожидания заголовков (`20 с` по умолчанию, параметр
`headersTimeoutMs`). Зависшее соединение обрывается и передаёт управление
следующему источнику, а не ждёт внешней отмены. Остановившаяся передача тела
по-прежнему ограничена отдельным таймером.

## Тесты

45 проверок в восьми файлах. Новые:

- установка из архива без конфига создаёт рабочий `audio-vulkan.json`;
- установленный движок без конфига ремонтируется без удаления файлов;
- зависший сервер не блокирует загрузку, переход к резервному адресу работает;
- одиночный зависший адрес даёт причину `timeout`;
- чужие провайдеры не запускаются.
