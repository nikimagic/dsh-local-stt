# 0.3.13 — официальные источники и безопасная подготовка

## Движки

- Главный источник — **официальные сборки**: `ROCm/FastFlowLM` 1.0.13 и
  `0xShug0/audio.cpp` 0.9.4 (вариант Vulkan для Windows x64).
- Наш архив из релиза `engines-1` остался резервом: если официальный URL
  недоступен, плагин пробует его.
- Локальный архив из папки проекта по-прежнему первый, если он есть.
- Размеры и SHA-256 закреплены для обоих вариантов; хеши взяты из `digest`
  GitHub-релиза и сверены локальным расчётом.
- Архив проверяется по маркеру (`flm.exe`) **до** переноса в каталог версии:
  неудачный архив не занимает каталог и не оставляет staging.

## Выбор источника моделей

- Явно выбранный в карточке источник больше не подменяется: `hf-mirror.com`
  используется только в авторежиме.
- В авторежиме переход к следующему адресу происходит и на HTTP-ошибке,
  а не только на сетевой.

## Устойчивость

- Хеши движков считаются асинхронно — проверка не блокирует Host.
- Клиентские запросы к GitHub и jsDelivr ограничены таймаутом 6 с.
- `localRoot` больше не лежит в пакете: машинный путь задаётся в профильном
  слое `cordis.patch.yml`.

## Тесты

35 проверок в шести файлах:

```text
zip       4    fetch      3    engines    6
models    6    provider   9    client     7
```

Добавлены проверки провайдера целиком (готовность, подготовка, повреждённый
движок, отсутствие сети, отказ `transcribe`, `targetFor`, отмена, `dispose`),
клиентского модуля (регистрация, фильтр, вызов `prepare`, тексты версий, сеть)
и приоритета официального архива над резервом.

Изолированный прогон пакета без доступа к каталогу проекта: все пути внутри
плагина, источники моделей — только Hugging Face, состояние `unprepared`.

Публикация и push — по отдельной команде.
