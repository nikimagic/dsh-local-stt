# 0.3.6 — локальная финализация

## Отмена старта

`startAbort` создаётся до ожидания `cleanupPromise`; `cancel()` прерывает
и очистку, и цикл ожидания порта. Проверка: отмена во время старта
завершилась примерно за 1 секунду, порт закрыт.

## Общий PID-файл двух DSH

PID-файл хранит `ownerPid` процесса DSH. Если файл принадлежит другому
живому DSH:

- сервер отвечает — второй экземпляр использует его;
- сервер не отвечает — запуск блокируется, файл не перезаписывается.

## Неизвестный старый PID

Если владельца проверить нельзя, `cleanupBlocked` запрещает запуск нового
сервера. Старый процесс не теряется.

## Остановка своего сервера

`stopOwned()` больше не делает `taskkill`, если дочерний процесс уже
завершился (`child.exitCode !== null`). Это исключает гонку с повторным PID
без дополнительного PowerShell-запроса на каждом распознавании.

## WAV

`audioSeconds()` теперь проходит RIFF-чанки и находит `fmt ` и `data` в
любом месте, а не только на фиксированных смещениях 12 и 36.
