# dsh-local-stt 0.3.13 — официальные движки

Плагин ставится в профиль пакетом и сам готовит движки и модели при первом
запуске. Вручную раскладывать 1,7 ГБ не нужно.

## Что нового

- **Движки берутся из официальных релизов:** `ROCm/FastFlowLM` 1.0.13 и
  `0xShug0/audio.cpp` 0.9.4 (Vulkan, Windows x64). Наш архив в релизе
  `engines-1` остался резервом на случай недоступности официального URL.
- **Порядок источников:** локальный архив из папки проекта → официальный
  URL → наш архив.
- Размеры и SHA-256 закреплены для обоих вариантов; хеши сверены с `digest`
  GitHub-релизов.
- **Модели:** Hugging Face по закреплённым ревизиям или локальная папка
  проекта. Явно выбранный источник больше не подменяется зеркалом.
- **Кнопка «Проверить обновления»** в шапке карточки плагина: SHA-256 движков
  и моделей плюс сравнение версии с GitHub.
- Проверка ничего не удаляет: повреждённый каталог движка остаётся на месте,
  staging проверяется до переноса.

## Исправления

- Архив без исполняемого файла больше не занимает каталог версии.
- Хеши движков считаются асинхронно — Host не блокируется.
- Клиентские запросы ограничены таймаутом 6 с.
- `localRoot` убран из пакета: машинный путь живёт в профильном слое.

## Тесты

35 проверок: zip, загрузка файлов, движки, модели, провайдер, клиентский
модуль. Изолированный прогон пакета без доступа к каталогу проекта проходит.

## Требования

- Windows x64, DSH 0.2.2-rc.1 и новее, штатный голосовой ввод DSH.
- NPU-путь: Ryzen AI 300 (XDNA2) с драйвером; альтернатива — Vulkan.
- Для офлайна: `localRoot` в профильном слое или `localSource` на `engines`.

После установки нужен перезапуск DSH.
