# Модели: первая загрузка

Модели весят около 1,6 ГБ, поэтому в Git и в пакет они не входят. Плагин
готовит их сам при первом запуске и показывает прогресс в штатной карточке
голосового ввода DSH. Перед моделями тем же способом ставится архив движка —
см. [ENGINES.md](ENGINES.md).

## Два источника

| Источник | Что делает | Когда доступен |
|---|---|---|
| **Hugging Face** | Скачивает файлы по закреплённой ревизии, проверяет размер и SHA-256 | Всегда |
| **Локальная папка** | Копирует те же файлы из каталога `engines` без сети | Если файлы уже лежат на диске |

Источник выбирается в карточке подготовки: **Голосовой ввод → Провайдер →
Источник**. Если ничего не выбирать, плагин берёт локальную папку, когда она
полная, иначе Hugging Face.

Локальная папка задаётся полем `localSource` или переменной окружения
`DSH_LOCAL_STT_SOURCES` — это путь к каталогу `engines` с раскладкой:

```text
<engines>\
  fastflowlm\models\Whisper-V3-Turbo-NPU2\
  audio-cpp\models\Orukeet-GGUF\
```

## Как это выглядит

```text
моделей нет            → «Первый запуск: скачать модели»
нажали «Скачать»       → прогресс по текущему файлу, байты и проценты
скачали и сверили      → «Локальные ресурсы подготовлены»
обрыв сети             → .part остаётся, следующая попытка продолжит с места обрыва
хеш не совпал          → .part удаляется, карточка показывает ошибку целостности
```

Пока моделей нет, распознавание не запускается: провайдер сразу отвечает
ошибкой со списком недостающих файлов.

## Куда кладутся файлы

Путь берётся из конфига провайдера: каталог `modelPath`. По умолчанию:

```text
Whisper  <plugin>\engines\fastflowlm\models\Whisper-V3-Turbo-NPU2\
Orukeet  <plugin>\engines\audio-cpp\models\Orukeet-GGUF\
```

Если каталог плагина только для чтения, укажите в конфиге `modelPath` и
`modelsDir` в доступное место либо задайте `DSH_LOCAL_STT_ENGINES`.

## Совместимость движков

Модель Whisper рассчитана на FastFlowLM 1.0.13 (`model.q4nx`, `flm_min_version`
0.9.14). Модель Orukeet — GGUF для audio.cpp 0.9.4. После обновления движков
сверьте ревизии в [ENGINES.md](ENGINES.md).

## Ручная подготовка

Если сеть недоступна, положите файлы из [ENGINES.md](ENGINES.md) вручную по
путям выше — плагин примет их, сверив размер и SHA-256. Хеши и ревизии
закреплены в `lib/models.js`.
