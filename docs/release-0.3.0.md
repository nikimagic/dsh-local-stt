# dsh-local-stt 0.3.0 — Whisper NPU + Orukeet Vulkan

Плагин переведён на два локальных ASR-сервера, которые уже работают на этой машине.

## Что изменилось

- **По умолчанию — Whisper large-v3-turbo на XDNA2 NPU** через FastFlowLM.
- **Альтернатива — Orukeet r3 на Radeon 880M** через audio.cpp/Vulkan.
- Плагин больше не запускает и не скачивает движки: он проверяет готовность
  `127.0.0.1:52626` и `127.0.0.1:8028` и отправляет WAV туда.
- Если сервер не отвечает, провайдер показывает ошибку и повторяет проверку
  каждые 5 секунд.
- Убраны старые провайдеры GigaAM и whisper.cpp из состава `dsh-local-stt`.

## Требования

```text
FastFlowLM:  flm serve --asr whisper-v3:turbo --host 127.0.0.1 --port 52626
audio.cpp:   Запустить audio.cpp.bat
```

## Проверка

- оба провайдера зарегистрированы и опрошены на живых серверах;
- Whisper NPU: ~1,7 с на короткую фразу;
- Orukeet Vulkan: ~0,16 с на короткую фразу;
- собранный профиль DSH подтверждает `defaultProvider: whisper-npu`.

После установки нужен перезапуск DSH, чтобы Host загрузил новый JavaScript-модуль.
