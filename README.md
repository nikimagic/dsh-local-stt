# dsh-local-stt

Локальный ASR для **штатного голосового ввода DeepSeek Harness**. Плагин
добавляет в переключатель провайдеров два варианта:

| Провайдер | Где считается | Роль |
|---|---|---|
| **Whisper large-v3-turbo (NPU)** | XDNA2 NPU через FastFlowLM | по умолчанию |
| **Orukeet r3 (Vulkan)** | Radeon 880M через audio.cpp | альтернатива |

Официальный `@deepseek-ai/dsh-experimental-voice-input-bundle` остаётся
хозяином микрофона, записи WAV и настроек. Плагин принимает готовый
16-кГц PCM16 WAV, запускает нужный C++-сервер, ждёт готовности, отправляет
аудио и останавливает сервер после ответа.

## Установка

В DSH откройте **Плагины → Добавить плагин** и укажите индекс:

```text
https://cdn.jsdelivr.net/gh/nikimagic/dsh-local-stt@main/docs/index.json
```

Установите `dsh-local-stt` и перезапустите DSH.

## Что запускается

Плагин не держит серверы в фоне. На каждое распознавание:

1. запускается `flm.exe` или `audiocpp_server.exe`;
2. плагин ждёт валидный `/v1/models` и `/health`;
3. WAV уходит на `127.0.0.1`;
4. после ответа процесс убивается, порт закрывается.

Питона в пути нет. Запускаются нативные C++-бинарники.

## Первый запуск

Плагин сам готовит всё необходимое: скачивает архив движка, распаковывает его,
затем скачивает модель. В карточке голосового ввода видно прогресс и объём;
пока чего-то не хватает, провайдер показывает `unprepared`, а распознавание
отвечает ошибкой со списком недостающих файлов.

| Что | Откуда | Размер |
|---|---|---:|
| Движок FastFlowLM 1.0.13 | релиз GitHub `engines-1` | 39,1 МБ |
| Движок audio.cpp 0.9.4 | релиз GitHub `engines-1` | 35,7 МБ |
| Модель Whisper | Hugging Face, ревизия закреплена | 622,9 МБ |
| Модель Orukeet | Hugging Face, ревизия закреплена | 873,5 МБ |

Для офлайна есть второй источник моделей — локальная папка с исходниками
(`localSource` / `DSH_LOCAL_STT_SOURCES`). Базовый адрес архивов движков
переопределяется полем `engines.baseUrl`, каталог установки — `engines.dir`.

Проверить целостность можно кнопкой **«Проверить обновления»** в панели
ввода: она пересчитывает SHA-256 всех файлов движка и модели и докачивает
повреждённое. То же делает кнопка «Скачать и подготовить» в карточке
голосового ввода.

Подробности: [docs/MODELS.md](docs/MODELS.md) и [docs/ENGINES.md](docs/ENGINES.md).

FastFlowLM:

```text
flm.exe serve --asr whisper-v3:turbo --port 52626
```

audio.cpp:

```text
audiocpp_server.exe --config audio-vulkan.json --port 8028 --no-ui
```

## Модели

Модели занимают около 1,6 ГБ и в Git не входят. Плагин готовит их при первом
запуске и показывает прогресс в штатной карточке голосового ввода. Источников
два:

- **Hugging Face** — скачивание по закреплённой ревизии, проверка размера и
  SHA-256; при сетевой ошибке — резервное зеркало `hf-mirror.com`;
- **Локальная папка** — копирование из каталога `engines` без сети.

Источник выбирается в карточке подготовки. Локальный каталог задаётся полем
`localSource` или переменной `DSH_LOCAL_STT_SOURCES`. Подробности —
[docs/MODELS.md](docs/MODELS.md).

Пути по умолчанию:

```text
FLM:      <plugin>\engines\fastflowlm\models\Whisper-V3-Turbo-NPU2\model.q4nx
Orukeet:  <plugin>\engines\audio-cpp\models\Orukeet-GGUF\orukeet-q8_0.gguf
```

`<plugin>` — каталог установленного плагина. Движки лежат в
`<plugin>\engines\fastflowlm\1.0.13` и `<plugin>\engines\audio-cpp\0.9.4`.
Путь к каталогу движков можно переопределить через
`DSH_LOCAL_STT_ENGINES`.

Модель Orukeet должна быть указана в
`engines\audio-cpp\0.9.4\config\audio-vulkan.json`.
Модель Whisper лежит в каталоге, на который указывает `FLM_MODEL_PATH`.

Сборка полного комплекта движков и моделей описана в
[docs/ENGINES.md](docs/ENGINES.md).

## Настройка

```yaml
- id: speech-to-text
  config:
    defaultProvider: whisper-npu
    language: ru
- id: speech-to-text-local
  config:
    localSource: C:\dsh\dsh-local-stt\engines
    whisper:
      baseUrl: http://127.0.0.1:52626
      model: whisper-v3:turbo
    orukeet:
      baseUrl: http://127.0.0.1:8028
      model: orukeet_q8_0
```

Можно переопределить `command`, `args`, `cwd`, `env`, `modelPath`,
`logPath`, `requestTimeoutMs`, `startupTimeoutMs`, `autoStart` и
`allowRemote`. Порт в `args` можно оставить как `{port}` — он подставится
из `baseUrl`.

`localSource` — каталог `engines` с готовыми моделями для второго источника
подготовки. `modelPath` задаёт и целевой файл модели, и каталог, рядом с
которым лягут остальные файлы модели.

`baseUrl` по умолчанию обязан указывать на loopback. Для внешнего адреса
нужно явно задать `allowRemote: true`; это осознанно отключает локальность.

## Ограничения

- Первый запуск требует скачать около 1,6 ГБ моделей либо указать локальную
  папку с ними; до этого распознавание не стартует.
- Официальная кнопка микрофона не отдаёт событие `mousedown`; провайдер
  получает WAV после остановки записи. Поэтому сервер стартует перед
  распознаванием, а не в момент клика. Для старта ровно по нажатию нужна
  своя клиентская кнопка.
- Cold start занимает около 4–5 секунд: загрузка модели при каждом запуске.
- Плагин проверяет, что на порту действительно FastFlowLM/audio.cpp, а не
  посторонний HTTP-сервис.
- Аудио не покидает машину, если `baseUrl` указывает на loopback.
